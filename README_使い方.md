# 静鉄ストア チラシ商品検索システム v4（管理者PDF取込版）

**管理者がチラシPDFを取り込み**、**お客様はそのデータを検索・献立で利用**できる
バージョンです。モード切替（管理者／お客様）を備えています。

1. **モード切替（パスワードなし）** — 画面右上で「👥 お客様」「🔑 管理者」を
   選べます。
   - **お客様**：検索・詳細・献立だけを利用できます（PDF取込ボタンは表示されません）。
   - **管理者**：上記に加えて、PDFの取り込み（JSONの読込/保存も）ができます。
   - 既定は「お客様」です。選んだモードはブラウザに記憶されます。
   - URL に `?admin` を付けて開くと管理者で起動します。
2. **データはPDFから** — 管理者が「チラシ全店版 テキスト版.pdf」を取り込むと、
   商品データに変換してブラウザに保存します。お客様はそのデータを見られます。
   （Webサイトからの自動取得は行いません。）
3. **献立に調理時間＋YouTube** — 各レシピに調理時間の目安と、作り方を調べる
   YouTube検索リンクが付きます。

> ⚠️ これは静的サイト（サーバー無し）のため、モード切替は**画面上の簡易的な
> 出し分け**です。パスワード認証ではなく、技術的に詳しい人はブラウザの操作で
> 管理者機能に到達できます。本格的なアクセス制御が必要な場合は、サーバー側での
> 認証が別途必要です（本デモの範囲外）。

> v1(`app`)・v2(`app-v2`)・v3(`app-v3`) はそのまま残してあります。v4 は
> `app-v4` フォルダです。

## 1. 使い方

### 管理者（データを登録する人）
1. 画面右上で「🔑 管理者」を選びます。
2. 「📄 PDFを取り込む」からPDFを選ぶ（またはドラッグ＆ドロップ）。
   対応形式は「チラシ全店版 テキスト版.pdf」（文字が選択できるテキスト版PDF）。
3. 取り込むと商品データに変換され、ブラウザに保存されます。以降はお客様も検索できます。

### お客様（見る人）
- 「👥 お客様」モードのまま、検索・詳細・献立を利用します。
- データがまだ無いときは「ただいまデータを準備中です」と表示されます。

### 起動
- `起動する.bat`、または `index.html` をブラウザで開きます。
- **重要**：ローカルの `file://` で開くと、ブラウザがPDF解析用のワーカーを
  ブロックする場合があります。うまく動かないときは簡易サーバーで開いてください。
  - 例：このフォルダで `npx serve .` または `python -m http.server`
  - **GitHub Pages など Web に置けば安定して動作します（推奨）。**

## 2. 検索・詳細・献立

### 検索
- キーワード検索、「300円以下」などの話し言葉検索、部門・並べ替え。
- 「一番安い野菜」なども利用できます（部門＝青果を自動判定し安い順に表示）。

### 詳細
- 📋 詳細で、販売期間・税抜/消費税/税込の内訳・メーカー・規格・JANを表示します。

### 献立ヒント
- 🍳 献立ヒントタブで、チラシの食材で作れる料理を提案。
- 各レシピに **⏱ 調理時間の目安** を表示（例：約20分）。
- **「▶ YouTubeで作り方」** ボタンで、その料理の作り方検索を新しいタブで開きます。
- 並べ替えに「時短（短い順）」を追加。ジャンル絞り込み・今すぐ作れる絞り込みも可。
- 商品ごとの「🍳 レシピ」、複数選択→「作れる料理」にも時間とYouTubeリンク付き。

## 3. ファイル構成

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面本体（これを開く） |
| `app.js` | 検索・詳細・レシピ・複数選択・モード切替・PDF/JSON入出力 |
| `pdf-extract.js` | PDF→商品データ変換 |
| `recipes.js` | レシピ・食材の知識ベース（調理時間 time を含む） |
| `icons.js` | 商品・料理の画像（絵文字）マッピング |
| `vendor/pdf.min.js` 他 | PDF.js（Apache-2.0、PDF取込用に同梱） |
| `起動する.bat` | ブラウザで開くショートカット |
| `説明スライド.html` | 説明用スライド（日本語7枚） |
| `DEPLOY_github_pages.md` | GitHub Pages への公開手順 |

---

## 4. ご注意

- 管理者が取り込んだチラシデータを検索するデモです。価格・在庫の
  リアルタイム照会は行いません。重要な情報は店頭・元チラシでご確認ください。
- 対応PDFはテキスト版（文字が選択できる）です。画像のみのPDFは読み取れません。
- 調理時間・レシピは一般的な目安です。YouTubeリンクは「作り方」検索結果を
  開くもので、特定の動画の内容を保証するものではありません。
- 掲載期間が前後しているデータには「期間要確認」と表示します。
- 税抜・税込の片方しか無い場合、消費税は軽減税率8%での目安計算です。
